I'm James, a dude based in New Zealand, currently learning how to work with older Unreal Engine systems and networks.

This site documents a personal project: reverse-engineering and reviving **Fury**, a 2007 PvP MMO built on Unreal Engine 3 that shut down in 2008. I still have the original client install, and I'm working through decompiling its UnrealScript packages, reverse-engineering its network protocol, and building a new server from scratch.

I'm writing this up as I go, mistakes and all, partly as a learning log for myself and partly because dev logs like this were part of what got me interested in software in the first place.

**Follow along:**

- [Posts](/posts/) — the dev log itself, roughly biweekly
- [Glossary](/glossary/) — running reference for terms (UnrealScript, replication, etc.) so posts don't have to re-explain basics
